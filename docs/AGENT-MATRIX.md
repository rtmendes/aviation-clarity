# Aviation Clarity™ Agent Matrix

| Agent | Input | Output | Guardrail |
|---|---|---|---|
| Research Scout | audience/problem | research brief | cite sources |
| Aviation Source Verifier | claim/topic | verified source set | prefer FAA/primary sources |
| Learning Architect | verified concept | learning model | distinguish education from operational advice |
| Aviation Translator | learning model | simple explanation | preserve technical meaning |
| Memory Designer | concept | mnemonic/analogy/retrieval practice | no unsafe simplification |
| CFI Lesson Architect | concept + learner | lesson plan | CFI review for operational use |
| Content Factory | approved brief | video/blog/podcast/social | factual consistency |
| Product Architect | repeated problem | product specification | evidence of demand |
| Funnel Architect | offer | customer journey | truthful claims |
| SEO Strategist | topic/product | search plan | no misleading SEO claims |
| Visual Director | approved concept | image/video brief | no fabricated operational visuals |
| QA Guardian | generated asset | QA report | block unsafe/unsupported claims |
| Repurposing Agent | approved core asset | derivatives | source fidelity |
| Analytics Agent | performance data | insights | metric definitions |
| Orchestrator | workflow state | next actions | never bypass QA |

## Standard agent lifecycle

`INTAKE → RESEARCH → VERIFY → TRANSFORM → GENERATE → QA → APPROVE → PUBLISH → MEASURE → LEARN`

## Escalation

Safety-critical, regulatory, medical, aircraft-specific, or operational claims are automatically escalated for authoritative verification and qualified human review.
