# Content Package Schema

Every approved topic can expand into a synchronized package:

- source-backed research brief
- learning model
- instructor lesson
- 100-page-book chapter candidate
- YouTube script
- podcast segment
- short-form scripts
- article
- email
- social posts
- worksheet/checklist
- product opportunity
- CTA

## Quality contract
All derivatives inherit the same verified claims. If a source changes or a claim is blocked, dependent assets return to QA.

## Book rule
A book chapter is not simply a long article. It must contain learning objectives, explanation, example/scenario, visual model, retrieval practice, application exercise, recap and source notes.
